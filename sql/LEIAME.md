# Banco de dados

Os scripts do MySQL ficam nesta pasta. O modelo completo (tabelas, chaves e relacionamentos) é entregue na Entrega 2.

Entidades planejadas: usuários, lojas, solicitações de vendedor, categorias, produtos, imagens de produto, endereços, cupons, pedidos, itens do pedido, histórico do pedido, avaliações, perguntas, favoritos, banners, configurações e logs de auditoria.
